# 프로젝트 요약 정리 (Localization / Around-View 기반 휠체어 트래킹)

## 0) 목적 및 개요

* 차량 어라운드뷰(서라운드뷰) 카메라 **2대(Left, Rear)**로 휠체어에 부착된 **ArUco 마커**를 감지하여 **휠체어의 위치/자세(Localization)** 를 추정한다.
* 제어 신호는 4가지:

  * **F**(전진), **B**(후진), **R**(오른쪽 회전), **L**(왼쪽 회전)

---

## 1) 카메라 캘리브레이션 데이터 (Localization 용)

### 1-1. 공통 광학 데이터 (Intrinsic Data)

두 카메라가 동일 렌즈 모델이라 **Intrinsic을 공유**한다.

* **Camera Matrix (`K`)**

  * `[[601.719, 0, 630.477], [0, 601.345, 367.212], [0, 0, 1]]`
  * 의미: 초점거리 및 주점(중심점)
* **Distortion (`D`)**

  * `[-0.18496, 0.02541, -0.01068, 0.00322]`
  * 의미: Fisheye 왜곡 계수
* **Marker Size (`size`)**

  * **0.25 m (25 cm)** : ArUco 마커 실제 크기
* **RMS Error (`rms`)**

  * **0.5898**
  * 메모: “시스템 신뢰도(양호)”로 판단

### 1-2. 카메라별 설치/제어 보정값 (Extrinsic & Control)

설치 위치가 다르므로 **각도 계산/제어용 보정값을 카메라별로 적용**한다.

| 항목            | Rear(후방) | Left(측방) | 설명                          |
| ------------- | -------: | -------: | --------------------------- |
| 각도 감도 `SENS`  |      1.6 |      1.6 | 어안 외곽 압축 상쇄 + 실제 각도 동기화     |
| 설치 보정각 `INST` |      0.0 |    113.0 | Left: 서쪽 90° + 남쪽 23° 편향 상쇄 |
| 영점 오프셋 `OFFS` |      0.0 |    50.84 | 휠체어 정북향 시 최종 Yaw를 0으로 고정    |

## 3) 어라운드뷰 카메라 설치 위치/각도 (추정 포함)

### 3-1. Left 카메라 (사이드미러 아래)

* **설치 위치**: 차량 **왼쪽**, **사이드미러 아래**
* **설치 높이**: **1100mm**

  * 정확한 자료는 없고 **대략 수치**
* **Pitch(아래 바라보는 각도)**

  * SVM 매뉴얼 기준: 아래로 20도
  * 실제 설정: **40도**(“거기까지 밖에 안됨”)
* **Yaw(좌우 방향)**

  * 정확한 수치는 없음
  * “앞 뒤 다 나오게” 조정
  * 추가로: **왼쪽 자체를 바라보는 방향에서 더 왼쪽으로 23도** 틀어져 있음
* 결론적으로 Left 카메라가 차량 후면 방향을 바라보는 영역 관련 메모:

  * 110cm에서 아래 기준 40도 + 차량 바라보는 기준에서 23도 틀어짐
  * 따라서 **차량 후면을 바라보는 영역은 157도**
  * **차량 영역은 보지 못함**

### 3-2. Rear 카메라 (번호등 아래)

* **설치 위치**: 차량 **후면 중앙**, 번호등 아래
* **설치 높이**: **1055mm**
* **Pitch(아래 바라보는 각도)**

  * SVM 매뉴얼 기준: 아래로 5~60도(범위 언급)
  * 실제 사용: **50도**
* 시야 메모:

  * 카메라가 **170도 범위까지 볼 수 있음**
