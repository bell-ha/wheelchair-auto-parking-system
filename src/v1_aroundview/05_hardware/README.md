# 05_hardware — 구동부와 차량 사양

TRACER 섀시 CAN 통신 절차는 [can_bus/README.md](can_bus/README.md) 에 있다.

## 기아 레이 내비게이션 사양 (조사)

| | |
|---|---|
| 화면 | 8인치 터치스크린 |
| CPU | 차량용 프로세서 — Nvidia Tegra 또는 Telechips 계열로 **추정** |
| RAM | 2~4 GB **추정** |
| 연결 | 기아 커넥트 — 내장 eSIM, OTA 업데이트 |

> **추정 근거** — 현대차 하드웨어가 5세대에서 RAM 2~4 GB 였고 이후 4~8 GB 로 올라갔다.
> 주요 공급사 텔레칩스의 Dolphin 시리즈 가이드에도 메모리 구성이 2~4 GB 로 나온다.
> **제조사 공식 사양이 아니다.**
