# Jetson Nano YOLO 부하 테스트 결과 보고

**테스트 일자**: 2026-07-22
**목적**: 휠체어 자동주차 시스템의 차량 부위 탐지 모델(YOLOv8n 커스텀, 6클래스)이
Jetson Nano에서 실시간 구동 가능한지 검증

## 1. 테스트 환경

| 항목 | 내용 |
|---|---|
| 보드 | NVIDIA Jetson Nano Developer Kit (4GB) |
| OS/SDK | JetPack 4.6 (L4T R32.6.1) |
| 소프트웨어 | Python 3.8.10, PyTorch 1.13 (CUDA 지원 빌드), Ultralytics YOLOv8 |
| 모델 | yolov8n 기반 커스텀 학습 모델 (best_v4_6cls.pt, 6.0MB) |
| 입력 | USB 웹캠, 추론 해상도 320px, 화면 표시 없이(headless) 구동 |
| 실행 스크립트 | src/v2_vision/scripts/live_camera.py |
| 전원 모드 | MAXN (10W, 4코어) + jetson_clocks 적용 |
| 스왑 | 기본 512MB → 4GB 파일 스왑 추가 (총 약 6GB) |

## 2. 구간별 부하 측정 결과

### ① 대기 상태 (YOLO 미실행, GUI 데스크톱만)

| 항목 | 측정값 |
|---|---|
| CPU | 코어당 0~8% |
| GPU (GR3D) | 0% |
| RAM | 약 2.2~2.6GB / 3.96GB |
| 온도 | CPU/GPU 약 40°C |
| 소비 전력 | 약 3.1~3.2W |

### ② 기동 구간 (모델 로드 + CUDA 초기화, 1회성)

| 항목 | 측정값 |
|---|---|
| 소요 시간 | 첫 프레임까지 약 43초 (환경에 따라 수 분) |
| CPU | 코어당 60~100% 버스트 |
| RAM | 2.6GB → 3.6GB로 급증 (약 1GB 추가 점유) |
| 소비 전력 | 최대 약 6.3W |
| 비고 | 스왑 512MB였던 초기 테스트에서는 이 구간에서 시스템 프리징 발생. **스왑 4GB 확장 후 해소** |

### ③ 실시간 추론 중 (정상 운용 상태, 약 2분 연속 측정)

| 항목 | 측정값 | 평가 |
|---|---|---|
| 처리 속도 | **지속 15 FPS** (구간에 따라 최대 22 FPS) | 카메라 공급 속도가 병목, 보드 여유 있음 |
| 프레임당 추론 시간 | 평균 42ms (이론상 ~23 FPS 여력) | |
| CPU | 코어당 20~60%, 포화 없음 | 여유 있음 |
| GPU (GR3D) | 5~63% 진동, 평균 약 35% | 여유 있음 (추가 연산 탑재 가능) |
| RAM | 3.55GB / 3.96GB에서 안정 유지 (증가 추세 없음) | 빠듯하나 안정 |
| 스왑 | 약 1.0~1.1GB / 6GB 사용, 완만 | 정상 |
| 온도 | CPU 47~49°C / GPU 46~48°C (팬 없음) | 스로틀링 여유 큼 |
| 소비 전력 | 평균 약 5.8W, 최대 6.4W | 아래 4절 참고 |

※ 요약 출력의 "평균 10.1 FPS"는 첫 프레임 초기화 43초가 포함된 수치로,
정상 운용 구간의 실효 성능은 15 FPS 이상임.

## 3. 결론

- **실시간 구동 가능 판정.** 추론 해상도 320 기준 지속 15 FPS를 유지했고,
  2분 연속 구동 동안 열·메모리·GPU 모두 안정 범위였음.
  저속 접근(도킹) 제어 용도로 충분한 프레임률.
- 현재 병목은 보드가 아니라 **웹캠의 프레임 공급(15fps)**.
  GPU 평균 사용률 35%로, 거리 추정 등 후처리 로직을 추가로 얹을 여유 있음.
- 기동 시 1회성 지연(약 40초~수 분)이 있으므로, 실제 운용 시
  시스템 부팅 후 미리 모델을 로드해두는 방식 필요.

## 4. 하드웨어 측 조치 요청/권고 사항

1. **전원**: 부하 시 소비 전력이 5.8~6.4W로, 마이크로USB(5V 2A=10W) 급전 시
   한계선 근처. 갑작스러운 전원 차단 방지를 위해 **DC 배럴잭 5V 4A 어댑터
   사용 권장** (J48 점퍼 장착 필요).
2. **저장 공간**: SD카드 26GB 중 96% 사용, 잔여 1.2GB. 방치 시 부팅 불능 위험
   → **용량 정리 또는 더 큰 SD카드로 교체 필요**.
3. **방열**: 현재 무팬 상태에서 48°C로 문제없으나, 여름철 실외/차내 환경이나
   장시간 연속 운용을 고려하면 **방열판+팬 장착 권장**.
4. (향후 성능 향상 옵션) TensorRT 변환 시 동일 모델로 추론 속도 2~3배 개선 가능
   — 추론 해상도 640 운용이 필요해질 경우의 카드로 보유.

## 5. 남은 검증 항목 (소프트웨어 측)

- 실제 차량(레이) 대상 검출 동작 확인 (본 테스트는 부하만 검증, 검출 0개는
  차량이 화면에 없었기 때문)
- 추론 해상도 640에서의 FPS 측정 (원거리 번호판 검출용)
- 젯슨 카메라 기준 초점거리 캘리브레이션 (거리 추정 로직 이식 시)
