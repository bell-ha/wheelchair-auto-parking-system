# 거리·각도 추정 작업 정리 (2026-07-09~10)

휠체어프로젝트의 다음 단계 작업 기록. README.md(프로젝트 전반)와 함께 읽을 것.

## 무엇을 만들었나

`scripts/distance_video.py` (신규) — v4 탐지 모델 위에 **번호판 실측 규격 기반
단안 거리·각도·방위각 추정**을 얹은 스크립트. 기존 test_video.py는 안 건드림.

실행:
```
python3.10 scripts/distance_video.py raw_videos/레이영상_1.mov models/best_v4_6cls.pt --conf 0.15
```
결과는 `outputs/distance/<영상>_dist.mp4` (좌상단 HUD로 값 표시).
※ 환경 주의: ultralytics/opencv는 **python3.10**(Frameworks)에 설치돼 있음.
README에는 3.11로 적혀 있는데 실제로는 3.10 (README 미수정).

## HUD에 표시되는 3가지 값 (도킹 제어의 3요소)

| 값 | 계산 방법 | 의미 (휠체어 관점) |
|---|---|---|
| 거리 (m) | 번호판 높이 155mm × 핀홀 공식: D = H_real·f / h_px | 얼마나 남았나 |
| yaw (deg, ±) | 크기 = 폭/높이 비율 acos, 부호 = 꼭짓점 키스톤(좌/우 변 길이 비교). 음수 = 왼쪽(L)에서 봄 | 차가 얼마나 비스듬한가 → 접근 자세 |
| bearing (deg, ±) | atan((번호판 중심 x − 화면중심) / f). 왼쪽 음수 | 차가 내 시야 어느 쪽인가 → 조향 |

- 레이 후면 번호판 실측 규격: **단형 335×155mm** (영상에서 육안 확인, "66라 5623")
- 초점거리: iPhone 13 mini 1x(35mm환산 26mm) 가정 → 1920px 기준 f≈1387px.
  **미보정 상태라 거리에 ±10~15% 스케일 오차 가능.** 줄자로 잰 거리에서 찍은
  영상으로 `--calib 1.0` 실행하면 `scripts/camera_calib.json`에 저장돼 자동 보정됨 (아직 안 함)
- 모든 값은 EMA(α=0.3)로 프레임 간 스무딩

## 핵심 구현 디테일 (수정 시 알아야 할 것)

1. **화면 경계에 잘린 번호판은 무시** — 잘린 박스는 작게 잡혀 거리가 부풀려짐
2. **yaw 부호(키스톤)**: YOLO 박스 크롭 → Otsu 이진화 → `RETR_LIST`(내부 윤곽 포함;
   흰 차체가 번호판을 둘러싸면 번호판 면이 blob 속 구멍이 되기 때문) → 4각형 후보 중
   크롭 경계에 안 닿는 것 우선 → 크기(YOLO 박스의 0.5~1.2배)·비율(0.6~4.5) 검증.
   좌/우 변 길이는 유클리드 거리(카메라 roll에 안전). 검출 실패 시 부호 없이 "(?)"
3. **키스톤으로 각도 "크기"까지 재는 건 포기** — 꼭짓점 1~2px 오차에 수십 도가
   흔들림(실측 -46° 오류 경험). 크기는 비율(acos) 방식이 안정적
4. `iou=0.5`로 predict — 같은 부위 중복 박스 억제
5. "가장 큰 번호판 박스"를 추적하므로 **다른 차 번호판을 따라갈 수 있음** (목표 차량
   필터 미구현 — 알려진 한계)

## 후미등 간격 방식 (실험, `--tail` 플래그, 기본 꺼짐)

아이디어: 번호판이 좌우 후미등의 정중앙(간격 실측 추정 1.3m) → 좌우 간격 비대칭으로
부호 있는 yaw. 기준선이 길어 원거리에서 유리할 것으로 기대했으나 실영상 검증 결과:
- 근거리(<3m): 후미등이 모서리를 감싸는 입체 렌즈라 박스 중심이 밀려 각도 과장
- 원거리(>7m): 신호가 거리²에 반비례해 박스 떨림에 묻힘 (±90° 포화)
- 다중 차량: 다른 차 후미등과 짝지어짐
방어 장치(위/아래 쌍 매칭 + 두 쌍 일치 검증 + 물리 크기 검증 + 3~7m 게이트)를 넣어
자기모순은 없어졌지만, **현재 영상 3개에는 레이가 3~7m 후면에 나오는 구간이 없어서
레이 대상 검증 미완**. 살리려면 7~8m 후면 직진 접근 영상 필요.

## 검증된 결과 (실영상 육안 확인)

- 정면 1.2m 후면: 거리 1.20m, yaw ~0(front) ✓
- 후면 오른쪽 45° (영상1 1초): 1.48m, **yaw +49°(R)**, bearing -21° ✓ (부호 모두 정확)
- 좁은 통로 오른쪽 비스듬 (영상3 20초): 0.83m, **+66°(R)** ✓
- 왼쪽 치우친 후면 (영상1 10초): -25°(L) ✓
- 거리 중앙값: 영상1 1.48m / 영상2 4.11m / 영상3 0.87m (장면과 부합)

## 센서/하드웨어 계획 (사용자 구상)

- **카메라를 팬 모터에 장착 예정** → 모터가 번호판을 화면 중앙에 추적.
  이때 화면상 bearing은 모터 제어 오차 신호가 되고, **모터 인코더 각도가 곧
  "휠체어 몸통 기준 차의 방향"**(= 조향 신호). yaw는 카메라를 돌려도 안 변함
  (위치 관계로 정해지는 값). 통합 시 `총 bearing = 모터각 + 화면 bearing`
- **초음파 센서**: 최근접(<1m) depth + 충돌 방지 담당. 비전은 식별·정렬 담당
