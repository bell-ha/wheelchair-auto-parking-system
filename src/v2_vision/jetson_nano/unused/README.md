# unused — 지금 안 쓰는 코드

현 워크플로우에서 대체된 코드 보관소. 지워도 되지만, 다시 꺼내 쓸 상황이
명확한 것들이라 이력 겸 남겨둠.

## live_camera.py
카메라 단독 실행 + YOLO 부하(FPS) 테스트 스크립트. `hardware/` 공용 계층이
생기기 전의 독립 스냅샷이라 파이프라인 코드를 자체 보유.
→ **대체:** `main.py --no-servo` (카메라만 테스트) 가 같은 역할을 함.
꺼내 쓸 상황: 순수 FPS 통계(평균/최대 추론시간 요약)가 필요한 부하테스트.

## test_sample.py
초음파+서보 수동 조작 curses 툴 (A/D/W/S 서보, 텔레메트리 표시).
`hardware/` 이전의 독립 스냅샷.
→ **대체:** `main.py` 가 같은 화면+조작에 비전까지 얹어서 대체함.
꺼내 쓸 상황: **카메라 없이** ESP32만 빠르게 점검하고 싶을 때 (main.py는
카메라가 없으면 안 뜸).

## joystick/
휠체어 주행 방향(0/90/180/270 각도 + stop) 제어용 코드. `keyboard.py`로 방향키 →
`joystick_controller.py` → `serial_link.py`로 시리얼 전송까지는 동작하지만,
**이 프로토콜을 받아줄 펌웨어가 아직 없음** (지금 연결된 ESP32는 `ultrasound/sample.ino`이고,
이건 초음파+서보 프로토콜만 처리함 — 주행 모터 명령은 무시됨).

실제 "조이스틱" 역할(방향 조종)은 서보 액추에이터(main.py 수동 / guide.py --drive 자동)가
대신하고 있어서, 이 폴더의 프로토콜은 당장 필요 없음. 실제 주행 모터/보드가 준비되면
그때 다시 꺼내 쓰거나, 새 펌웨어에 맞게 프로토콜을 고쳐서 씀.
