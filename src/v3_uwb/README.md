# V3 — UWB 측위

휠체어 위치를 카메라 대신 **UWB 무선 거리 측정**으로 구한다.
차에 **앵커**를 달고, 휠체어에 **태그**를 단다. 태그가 앵커까지의 거리를 1초에 10번 잰다.

카메라를 쓰지 않으니 V1·V2에서 막혔던 문제(렌즈 왜곡, 시야 밖에서 위치를 잃음, 휠체어에 달린 장비가 많음)를
함께 피할 수 있다는 가정에서 출발했다. 이 폴더는 그 가정을 **측정으로 확인하는 것**부터 한다.

**지금 상태 (2026-10-30)** — 보드 4개 중 2개(앵커 1, 태그 1)로 거리 측정이 동작한다.
0.41 m에서 300번 모두 성공, 평균 +5.5 cm 길게 나옴. 줄자와 비교하는 실험 1 진행 중.

## 폴더

```
v3_uwb/
├── README.md           지금 이 문서
├── docs/
│   ├── 원리.txt          어떻게 거리를 재나, 높이 차이, 오차 원인, 와이파이 없이 통신하는 방식
│   ├── 하드웨어.txt       보드, 보드 목록, 펌웨어 올리는 법, 주의할 점, 내구성
│   └── 문제해결.txt       증상별 해결 (연결 끊김, 업로드 실패 등)
├── firmware/           보드에 올리는 코드
│   ├── uwb_anchor/       앵커 (차에 다는 쪽)
│   └── uwb_tag/          태그 (휠체어 쪽)
├── tools/              맥에서 실행하는 코드
│   ├── live_view.py      실시간 화면 + 기록
│   ├── analyze.py        기록 분석
│   └── lib/              위 두 개가 쓰는 부품 (직접 실행하지 않음)
└── experiments/        실험마다 폴더 하나
    └── 01_거리정확도/     실험노트.txt + data/ (기록 CSV)
```

## 사용법

1. **펌웨어 올리기** — 앵커 보드에 `firmware/uwb_anchor`, 태그 보드에 `firmware/uwb_tag`.
   처음이면 [docs/하드웨어.txt](docs/하드웨어.txt)의 "준비"와 "펌웨어 올리기"를 본다.
2. **화면 켜기** — 보드를 맥에 꽂고:
   ```bash
   cd src/v3_uwb
   python3 tools/live_view.py
   ```
   브라우저가 열리고 보드마다 카드가 생긴다. 실제 거리를 적고 "기록 시작"을 누르면 CSV가 쌓인다.
3. **분석** — `python3 tools/analyze.py`

문제가 생기면 [docs/문제해결.txt](docs/문제해결.txt).
