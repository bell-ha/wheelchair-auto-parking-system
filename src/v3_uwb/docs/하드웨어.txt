하드웨어
========

보드 구성, 보드 목록, 펌웨어 올리는 법, 다룰 때 주의할 점, 상시 설치할 때의 내구성.
문제가 생겼을 때는 문제해결.txt를 본다.


1. 보드
-------

ESP32 UWB DW3000 (Makerfabs 호환품, 빨간 기판) x 4개

  두뇌      ESP32-WROOM-32E. 우리가 짠 코드가 여기서 돈다.
  무선      "UWB-X3" DW3000 모듈 (금속 덮개 부분).
            칩 ID deca0302 = DW3000 C0, 각도 측정(PDoA) 없음. 거리만 잰다.
  안테나    UWB 모듈 옆 흰색 부분 (UWB4A 스티커). 거리의 기준점.
  USB       CP2104 칩. 맥 기본 드라이버로 잡힌다. 포트 이름 끝이 이 칩의 고유번호.
  전원      micro USB 5 V (4.8~5.5 V).
  버튼      RST(재시작), FLASH(업로드가 안 될 때 누른 채로)

기판 안에서 이미 연결된 핀 (ESP32 <-> DW3000)
  RST 27, IRQ 34, CS 4, SPI SCK 18 / MISO 19 / MOSI 23
  이 6개는 다른 용도로 쓰지 않는다. 옆의 핀 헤더는 ESP32의 남는 핀이다.
  V2 ultrasound/sample.ino 핀 배치(18, 19, 23, 27, 34 사용)는 그대로 옮길 수 없다.

부팅할 때마다 나오는 "XTRIM OTP READ FAIL"
  호환 모듈이라 칩 안에 시계 보정값이 비어 있다는 경고다. 라이브러리가 기본값으로 채우고,
  측정할 때마다 시계 차이를 따로 보정하므로 무시해도 된다.


2. 보드 목록
------------

라벨 = USB 칩 고유번호 끝 4자리. 보드에 스티커로 붙여 둔다.

  DFCA   고유번호 030ADFCA   MAC d8:bf:c0:86:c7:7c   태그   uwb_tag 업로드, 정상
  DFBB   고유번호 030ADFBB   MAC d8:bf:c0:84:f3:b4   앵커   uwb_anchor 업로드(115200), 정상
  (3번)  미점검 - 공장 펌웨어 그대로
  (4번)  미점검 - 공장 펌웨어 그대로

안테나 지연 보정값이 정해지면 여기에 보드별로 적는다.


3. 처음 한 번만 하는 준비
-------------------------

(1) 라이브러리
    https://github.com/Makerfabs/Makerfabs-ESP32-UWB-DW3000 (커밋 9d449b8, 2026-07-01에서 확인)
    에서 Dw3000 폴더를 ~/Documents/Arduino/libraries/ 에 복사한다.
(2) 보드 패키지
    Arduino IDE 보드 매니저에서 "esp32 (Espressif)" 2.0.17 -> 보드는 "ESP32 Dev Module".
    "Arduino ESP32"는 다른 패키지라 고르지 않는다. 3.x 버전은 확인 안 함.
(3) Python
    pyserial (pip install pyserial)


4. 펌웨어 올리기
----------------

Arduino IDE
  firmware/uwb_tag/uwb_tag.ino (또는 uwb_anchor) 열기 -> 보드·포트 고르기 -> 업로드.
  도구 메뉴의 Upload Speed는 115200으로 둔다 (빠른 속도는 중간에 끊긴 적이 있다).

터미널 (IDE 안에 들어 있는 arduino-cli)
  CLI="/Applications/Arduino IDE.app/Contents/Resources/app/lib/backend/resources/arduino-cli"
  cd src/v3_uwb/firmware
  "$CLI" compile --fqbn esp32:esp32:esp32:UploadSpeed=115200 --upload -p /dev/cu.usbserial-030ADFCA uwb_tag
  "$CLI" compile --fqbn esp32:esp32:esp32:UploadSpeed=115200 --upload -p /dev/cu.usbserial-030ADFBB uwb_anchor

- 화면(live_view.py)이 켜져 있으면 그 보드 카드에서 "포트 놓기"를 먼저 누른다. 끝나면 "다시 잡기".
- FLASH 버튼은 보통 필요 없다. "Connecting..."에서 멈출 때만 누른 채로 다시.
- 앵커와 태그는 짝이다. 무선 설정이나 안테나 지연값(TX_ANT_DLY, RX_ANT_DLY)을 바꾸면 둘 다 바꿔 올린다.

펌웨어가 하는 일
  uwb_anchor  태그의 poll을 받으면 0.9 ms 뒤 답한다. 1초마다 "# replies=N per 1s" 출력.
  uwb_tag     1초에 10번 poll을 보내 거리를 계산하고, 한 줄씩 출력한다.
  둘 다 Makerfabs 예제(range_tx / range_rx)에서 출발했다. 바꾼 점은 각 .ino 맨 위에 적었다.

태그가 내보내는 한 줄 (화면이 읽어서 보여 주고, 기록하면 CSV로 저장된다)
  R,ms,seq,dist_m,clk_ppm,C,F1,F2,F3,N,D   측정 성공
  E,ms,seq,reason                          측정 실패 (timeout, rx_err, bad_frame)

  dist_m    거리 (m)
  clk_ppm   앵커 대비 태그 시계 차이
  C, F1~F3, N, D   수신 신호 원시값. dBm 환산은 tools/lib/uwb_proto.py가 한다.
                   (원시값으로 보내는 이유: 공식이 틀려도 펌웨어를 다시 올리지 않고 파이썬만 고치면 된다)


5. 다룰 때 주의할 점
--------------------

보드
- 실험 중 전원은 USB로. 핀으로 넣을 때는 5 V는 5V 핀, 3V3 핀에는 3.3 V만.
  3V3 핀에 5 V를 넣으면 칩이 바로 망가진다. 핀 이름은 기판 인쇄로 확인한다.
- 금속 위(맥북 위, 철제 책상, 공구)에 올려놓지 않는다. 뒷면이 합선되고 안테나도 방해받는다.
- 만지기 전에 문고리 같은 금속을 한 번 짚어 정전기를 뺀다. 모서리를 잡고, UWB 모듈과 안테나는 만지지 않는다.
- micro USB는 똑바로 뽑는다. 보드에서 가장 약한 부품이다.

측정
- 아직 공장 펌웨어인 보드는 꺼 둔다.
  공장 펌웨어(SIMPLE TX)가 우리와 같은 설정으로 0.5초마다 신호를 쏴서 측정과 겹친다.
- 앵커는 한 번에 1개만 켠다. 지금 펌웨어는 앵커끼리 구분을 못 해 동시에 답한다.
- 안테나 높이를 같게, 방향은 고정, 기준점은 안테나 중심.
- 기록하는 동안은 보드에서 떨어져 있고 만지지 않는다. 사람 몸이 반사와 가림을 만든다.
- 0.5 m보다 가까운 거리는 기준으로 쓰지 않는다. 책상 반사가 섞이기 쉽다. 1 m 이상에서 잰다.
- 보조배터리로 앵커를 켤 때, 시간이 지나 실패가 늘면 배터리를 의심한다.
  보조배터리는 적은 전류만 쓰면 스스로 꺼지는 것이 많다.

맥과 프로그램
- 한 포트는 한 프로그램만 연다. 화면, Arduino 시리얼 모니터, 업로드가 겹치면 실패한다.
- 화면을 켜면 맥에 꽂힌 보드가 한 번 재부팅된다. 그래서 처음 몇 번의 실패는 정상이다.


6. 내구성 - 차나 휠체어에 상시로 달 때
---------------------------------------

지금 보드는 맨 기판 + 호환 모듈이라 실내 실험용이다. 상시로 달려면 아래를 갖춰야 한다.

열
  여름 차 안, 대시보드는 70도를 넘기도 한다. ESP32 모듈은 -40~85도 등급이고,
  호환 모듈 UWB-X3는 등급을 알 수 없다. 케이스 안은 자체 발열로 더 뜨겁다.
  -> 햇빛 직사와 대시보드를 피한다. 밝은 색 케이스, 통풍 구멍.

케이스 재질
  PLA는 60도쯤에서 물러진다.
  -> 3D 프린팅은 PETG 이상, 차 밖에 달면 ASA (열과 자외선에 강함).
  -> 금속, 탄소섬유, 금속 도장은 안 된다. 전파를 막는다.

진동
  휠체어 주행, 차 문 여닫을 때. micro USB가 먼저 헐거워지고, 기판이 휘면 납땜이 갈라진다.
  -> 모서리 구멍 4개로 나사 고정. 케이블은 케이스에 묶어 커넥터에 힘이 안 가게.
  -> 상시 설치는 micro USB 대신 5V, GND 핀에 전선을 납땜하고 열수축 튜브로 감싼다.

물과 먼지
  주차장은 실외다.
  -> 방수 케이스(IP65 정도)와 케이블 구멍 마개. 습기 대비로 실리카겔.

정전기
  사람이 수시로 만지는 휠체어.
  -> 플라스틱 케이스로 덮어 기판이 손에 닿지 않게.

전원
  차 12 V는 시동 걸 때 전압이 크게 튄다. 휠체어 배터리는 24 V.
  -> 서지 보호가 있는 차량용 12 V -> 5 V 변환기, 휠체어는 24 V -> 5 V 변환기.
  -> 앵커를 늘 켜 두면 차 배터리가 닳는다. 시동(ACC) 전원에 연결하거나 절전 대기를 설계한다.

안테나 주변
  차체 금속에 바로 붙이면 측정이 틀어진다.
  -> 금속에서 몇 cm 띄우고 플라스틱 창으로 둔다.
  -> 케이스를 씌운 상태에서 안테나 지연을 다시 보정한다. 케이스도 측정값을 바꾼다.

예비 부품
  앵커 3 + 태그 1이면 4개가 전부라 예비가 없다. 호환품이라 품질 편차도 있다.
  -> 1~2개 더 사 둔다. 보드마다 라벨과 보정값을 2절 목록에 기록한다.
